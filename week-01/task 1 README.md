# Week 1 - Task 1: Tourism & Hospitality Industry Analysis

This directory contains the details and dataset analysis for **Task 1 (Tourism & Hospitality Industry Analysis)** of Week 1.

---

## 📌 Overview
In this task, we performed exploratory data analysis (EDA) and market insights generation on the Tourism and Hospitality sector dataset to identify customer trends, spending patterns, and booking behaviors.

---

## 🛠️ Key Highlights
- **Data Cleaning & Preprocessing:** Handled missing values, standardized categories, and cleaned temporal attributes.
- **Exploratory Data Analysis:** Analyzed customer segments, preferred travel types, and peak booking seasons.
- **Insights & Visualizations:** Generated visual breakdowns to identify key revenue drivers and customer satisfaction metrics.

---

## 📁 Files Included
- [`week_1_task_1.ipynb`](./week_1_task_1.ipynb): Jupyter/Colab notebook containing data analysis, cleaning steps, and visualization charts.
